DESCRIPTION DU PROJET :

Diamond Jewellery est un site e-commerce de vente de bijoux. 
Le projet est développé en HTML5, CSS3 et JavaScript , 

FONCTIONNALITÉS PRINCIPALES & LOGIQUE TECHNIQUE :

1. Catalogue & Panier :
   - Filtrage et affichage dynamique des articles.
   - Système d'ajout au panier fluide (l'utilisateur reste sur la page produit).


2. Gestion de Session (sessionStorage) :
   - Restriction du panier : la validation finale de la commande nécessite 
     obligatoirement d'être connecté.
   - Utilisation du sessionStorage du navigateur pour simuler une session active. 
     La session s'efface automatiquement dès la fermeture de l'onglet pour les tests.
